# QA Defect and Retest Policy

Defect fields:
- Defect ID
- QA issue
- Severity
- Finding
- Expected
- Actual
- Impact
- Required fix
- Owner
- Status
- Fix evidence
- Retest result

Critical/High defects block successor work. Every fixed defect returns to the originating QA issue for retest. Silent edits do not count as rework evidence.
